# Облачный автозапуск отчёта по заказам WB+Ozon

Каждый день в **08:00 МСК** GitHub сам собирает отчёт по всем брендам и
рассылает: Google-таблицы перезаписываются, сводки и Excel уходят в Telegram.
Твой компьютер не нужен.

## Установка (один раз, ~10 минут)

1. **Аккаунт GitHub** — зарегистрируйся на github.com, если нет.

2. **Создай ПРИВАТНЫЙ репозиторий**: github.com → New repository → имя
   `iav-orders-cloud` → обязательно **Private** → Create.

3. **Загрузи файлы**: в репозитории «uploading an existing file» → перетащи
   ВСЁ содержимое этой папки (включая папку `.github` — если она не видна
   в Finder, нажми Cmd+Shift+точка) → Commit.
   Либо через GitHub Desktop, если привычнее.

4. **Добавь два секрета**: Settings → Secrets and variables → Actions →
   New repository secret:
   - имя `API_KEYS_FILE`, значение — **полное содержимое** твоего файла
     `api_keys.txt` (открой его и скопируй целиком);
   - имя `GOOGLE_SA_JSON`, значение — полное содержимое файла сервисного
     аккаунта `claude-reports-….json`.

5. **Проверь запуском вручную**: вкладка Actions → «Ежедневный отчёт по
   заказам WB+Ozon» → Run workflow. Прогон занимает 10–20 минут
   (лимит WB — 3 запроса/мин). Если в Telegram пришли сводки — всё работает.

Дальше он запускается сам каждый день в 08:00 МСК.

## Что важно знать

- **Секреты в безопасности**: ключи хранятся в зашифрованных GitHub Secrets,
  в коде и логах их нет, репозиторий приватный.
- **История заказов** копится в `state/history_*.json` и коммитится обратно
  в репозиторий после каждого прогона — ничего не перекачивается заново.
- **Excel-файлы** доступны во вкладке Actions → прогон → Artifacts
  (хранятся 14 дней) и приходят в Telegram.
- **Новый бренд подключается без кода**: добавь в секрет `API_KEYS_FILE`
  строки `<БРЕНД>_GSHEET_ID` / `<БРЕНД>_TG_CHATS` — подхватится сам.
- Поменять время: `.github/workflows/daily-report.yml`, строка `cron`
  (время в UTC, МСК = UTC+3: 08:00 МСК → `0 5 * * *`).
- Если обновил ключ (например, перевыпустил WB-токен) — просто обнови
  секрет `API_KEYS_FILE`.

## Если прогон упал

Вкладка Actions → красный прогон → открой лог шага «Конвейер по всем
брендам» — там будет написано, какой бренд и на чём споткнулся. Самые
частые причины: истёк токен WB (перевыпустить), WB API временно отдаёт
5xx (перезапустить прогон кнопкой Run workflow).
